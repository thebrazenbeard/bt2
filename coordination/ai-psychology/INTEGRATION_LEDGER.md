## Hostile functional gap map, prioritized

1. **P0 — Evidence-grounded drive closure:** durable provenance-bearing outcome/need observation -> idempotent need-state update -> consequent MESO pressure and Volition satiation change. Current need level and satisfaction values are caller supplied. An internal prose claim cannot certify corrective success.
2. **P1 — Interoception/allostasis:** validated internal resource state, observation uncertainty, provenance and staleness; predictive resource costs/setpoint dynamics rather than only static deficits. This is computational, not an assertion of biological interoception.
3. **P1 — Affect regulation:** competing appraisals, valence/arousal, inhibition, context-dependent reappraisal, time-scale separation and overload recovery. A single salience/reward number is insufficient.
4. **P1 — Procedural habit/executive conflict:** repeated event hazard is not learned context->action policy; veto and authorization must still remain distinct.
5. **P2 — Attachment, social context and self-model:** durable relation-specific trust and current consent, correction and disagreement; trait/identity claims grounded in admitted evidence, not generated labels.
6. **P2 — Developmental/embodiment grounding:** admitted sensory/bodily observations, learned calibration and bounded plasticity, negative transfer/regression tests.
7. **P2 — Wanting / liking / learning separation:** incentive salience, positive valence proxy and conditioned associations are analytically different; no claim that scores prove phenomenology.

## Minimum falsification suite for a genuine computational drive

- Same deficit persists across multiple bounded cycles *without* a fresh user prompt. Reappraisal and protection veto can interrupt it.
- Verified corrective outcome with source/evidence/event ID reduces subsequent deficit/drive and records exactly one satisfaction update.
- Duplicate, forged, stale, contradictory or self-generated success evidence cannot silently produce satisfaction; failed action is not success.
- No path converts salience, repetition, pleasure proxy, self-chosen labels, or goal pressure into external authority.
- Behavior and held-out results are verified separately from source unit tests and from runtime installation.
