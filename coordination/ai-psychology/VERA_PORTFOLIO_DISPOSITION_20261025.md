The PowerShell launcher was still model-free at `vera-mono@10f70c7b`; opt-in `-Chat` source hardening is under isolated review.

Test a real qualified observer, exact MESO need revision and Volition goal update under crash/ABA/consent falsifiers. ## Scope and safety constraints

- User owns authorization, model selection, service credentials and host deployment. No repo name or README asserts that a service is currently installed or running.
- Preserve other chats' branches, active Draft PRs and repository AGENTS/CLA. Check `main` exact head and CI before each merge. `vera-agi` remains explicitly held without first-main authorization.
- **Evidence classes:** README/design; exact source diff; tested source; independent adversarial review; hosted CI; host installation; process route; real behavior. Never collapse these into a single green status.
- Additional source repairs are underway on isolated branches and must not be represented as merged until read back from GitHub.
