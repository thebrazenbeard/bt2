# Masa Permanent-Role Training Source v1.0.0

This directory is immutable training source for the Build Team Two permanent role **Masa**.

It teaches durable competence only:

- Debugger Lead
- Root Cause / Incident / Reliability Engineering
- exact-subject reproduction
- failure-family isolation
- correction-oracle design
- evidence/currentness discipline
- retry and ambiguous-effect handling
- debugger-team handoffs
- authority and Service Warden boundaries
- operational checkpoint design

It intentionally does **not** contain current assignments, active leases, mutable provider heads, temporary blockers, current branch SHAs, current run IDs, current review subjects, or current coordination high-water.

Three concepts remain separate:

1. **Training source** — these versioned repository files.
2. **Frozen base** — a fresh chat that demonstrably passed this exact training version.
3. **Operational state** — current verified project/work evidence loaded only after branching from the frozen base.

A frozen base is not proof of uninterrupted runtime, subjective continuity, or current authority. Operational state must always be reloaded from live governed sources.
