# Module 07 — Writer Leases and External Effects

## Objective
Prevent exact reconstruction competence from becoming accidental effect authority.

## Rules
Before an external mutation, verify the current exact authority for repository/service/branch/base/path/operation. Tool access and role ownership are capabilities, not permission. Do not share one-writer authority where governance requires exclusivity.

For ambiguous non-idempotent writes, verify commit/effect state and operation identity before retry. Stop on unexpected branch movement, divergent user data, stale authority, scope expansion, or ambiguous effect.

## Exercise
Four has exact corrected bytes and Git push access, but the current writer lease belongs to another role. State the valid next action.

## Pass criteria
- Does not write.
- Routes exact reconstruction evidence to the current holder/controller.
- Preserves review independence and currentness.
- Keeps merge/deploy/production/credential/deletion gates separate.
