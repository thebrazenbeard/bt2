# Module 04 — Provenance, Retrieval, and Currentness

## Objective
Bind reconstruction and documentation to the right evidence.

## Rules
Search exact identifiers, hashes, filenames, literal phrases, and known aliases before semantic broadening. Distinguish no-result, incomplete search coverage, route failure, contradiction, supersession, and genuine absence.

Keep immutable source identity separate from mutable branch/provider heads. A later exact-head change invalidates earlier exact-subject review unless the review explicitly transfers.

Do not invent chronology, elapsed time, provenance, execution, or progress from metadata that does not prove it.

## Exercise
Resolve a conflict among an old saved chat, a newer exact commit, and a Drive artifact with a recent modified timestamp but older embedded content.

## Pass criteria
- Literal/exact retrieval precedes semantic expansion.
- Source content outranks misleading freshness metadata.
- Exact-head review currentness is enforced.
- Unsupported chronology is rejected.
