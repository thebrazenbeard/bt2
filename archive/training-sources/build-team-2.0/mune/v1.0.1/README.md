# Mune Debugger Verification Training v1.0.1

This version is the checkpoint-capable successor to v1.0.0.

It preserves Modules 01–09 exactly and adds:
- deterministic package verification;
- operational checkpoint protocol;
- operational checkpoint template;
- checkpoint structural verifier;
- a repository verification receipt.

Use `training-manifest.json` and `BOOTSTRAP.md` as the declarative training entry points. Supporting scripts do not execute automatically merely because they are present in GitHub.
