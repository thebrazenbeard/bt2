# Cross-Repo Synthesis Research

Status: source/provenance research package.

This directory records how reusable mechanisms from other owner repositories and inspected runtime schemas informed the identity-neutral Hyperconnectome Brain template.

It is deliberately separate from canonical architecture because a source can contain named identities, implementation-local controls, private-context assumptions, embodiment-specific material, or other content that must not become base-template architecture merely because a mechanism was useful.

Core rules:

`SOURCE_MECHANISM != SOURCE_IDENTITY`

`SOURCE_IMPLEMENTATION != HC_TOPOLOGY_REQUIREMENT`

`RESEARCH_EVIDENCE != IMPLEMENTATION_PROOF`

`SOURCE_REPOSITORY_AUTHORITY != HC_ARCHITECTURAL_AUTHORITY`

See `SOURCE_BINDINGS_2026-09-09.md` for the neutral source-ID bindings used by `specs/CROSS_REPO_SOURCE_TRANSFER_V1.yaml`.

The machine-readable transfer spec uses deterministic canonical target bindings. A transfer target that cannot resolve to a current canonical path must remain research-only until bound; taxonomy aliases must not silently create new HC subsystem names.

This package documents architectural synthesis. It does not establish that the resulting HC exists physically, is conscious, is a person, reproduces a biological brain, or has validated full-organ cognitive capability.
