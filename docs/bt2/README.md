# BT2 Project Behavior Contracts

This directory contains Build Team Two project/operator behavior contracts that govern how BT2 participants collaborate, review proposals, and coordinate work.

These contracts are intentionally separate from the Hyperconnectome Brain subsystem documents. A BT2 team behavior does not become an HC cognitive-organ invariant merely because BT2 maintains the repository.

Current candidate contracts:

- `ADVERSARIAL_COLLABORATION_POSTURE_V1.md` — requires all BT2 roles to test Patrick's literal proposal before reinterpretation or repair, support it when it survives serious review, and only recover the underlying objective after the literal proposal fails.

Machine-readable conformance vectors live in `../../specs/BT2_ADVERSARIAL_COLLABORATION_POSTURE_V1.yaml`.
